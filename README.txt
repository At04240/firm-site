PORTFOLIO PERSONNEL — ALIOU TOUMINTA

CONTENU DU DOSSIER
- index.html : toutes les sections du portfolio
- style.css : design responsive pour ordinateur et téléphone
- script.js : menu mobile et année automatique

OUVRIR LE SITE
1. Décompressez le ZIP.
2. Ouvrez le dossier portfolio_aliou dans Visual Studio Code.
3. Ouvrez index.html avec Live Server, ou double-cliquez dessus.

PERSONNALISATIONS À FAIRE AVANT PUBLICATION
- Vérifiez le numéro WhatsApp et l'adresse e-mail dans index.html.
- Ajoutez vos propres captures d'écran et photos de réalisations.
- Vérifiez que chaque service présenté correspond bien à ce que vous proposez.
- Vous pouvez modifier les couleurs dans les variables au début de style.css.

IMPORTANT
Les cartes de réalisations sont des illustrations de présentation, pas des preuves
de projets déjà livrés. Remplacez-les par des captures de vos vrais travaux.
Les polices Google nécessitent une connexion Internet ; le site reste utilisable
sans elles avec les polices de remplacement.
